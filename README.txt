LIGHT GARDEN 야간 별빛 축제 웹사이트 (수업 과제용)

실행 방법
1. ZIP 파일을 압축 해제합니다.
2. light_garden_festival 폴더 안의 index.html을 Chrome 또는 Edge에서 엽니다.
3. 사전예약 버튼을 누르면 reservation.html 신청 페이지로 이동합니다.
4. 전체 일정 보기 / 전체 프로그램 보기 버튼을 누르면 팝업이 열립니다.

폴더 구성
- index.html : 메인 행사 안내 페이지
- reservation.html : 사전예약 페이지
- css/style.css : 전체 디자인 및 반응형 스타일
- js/main.js : 모바일 메뉴, 일정 및 프로그램 팝업
- js/reservation.js : 신청 폼 검증 및 완료 화면
- assets/light-garden-hero.png : 웹페이지에 실제 삽입한 신규 제작 메인 이미지
- assets/reference-image.png : 사용자가 제공한 디자인 참고 이미지

주의
- 행사 날짜, 장소, 프로그램은 과제용 가상 설정입니다.
- 사전예약은 데모이며 실제 서버 저장, 이메일 발송, 결제 기능은 없습니다.
- Google Fonts 웹폰트는 인터넷 연결 시 적용됩니다.
